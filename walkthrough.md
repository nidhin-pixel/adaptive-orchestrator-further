## 3. Passing the `ModelDescriptor`

The `ModelDescriptor` holds identity, capabilities, and pricing information. It uses Pydantic with `ConfigDict(extra="allow")`, meaning any custom metadata Akash's router passes will be preserved without raising validation errors:

```python
model_desc = ModelDescriptor(
    model_id="gpt-4o",
    provider="openai",
    tier="flagship",
    supported_capabilities=["chat", "tools", "vision"],
    context_window=128000,
    input_price_per_million=2.50,
    output_price_per_million=10.00,
    enabled=True,
    # Any custom routing tags will also be accepted:
    # routing_group="primary-tier-1"
)
```

## 4. Provider Execution & Contract Mapping

Both `OpenAICompatibleProvider` and `AnthropicProvider` implement the asynchronous contract:

```python
async def call(
    prompt: str,
    model: ModelDescriptor,
    context: Optional[Dict[str, Any]] = None,
) -> ExecutionResult:
```

### Call Example:

```python
provider = OpenAICompatibleProvider()

result: ExecutionResult = await provider.call(
    prompt="Generate an executive summary of quarterly churn.",
    model=model_desc,
    context={
        "system_prompt": "You are a senior data analyst.",
        "temperature": 0.2,
        "max_tokens": 1024,
    }
)
```

### Contract Guarantee:

The returned object is guaranteed to be an `ExecutionResult` containing:

| Field | Type | Description |
|---|---|---|
| `content` | `str` | Text content generated by the model (empty string on failure) |
| `model_id` | `str` | The ID of the model that handled the call |
| `success` | `bool` | `True` if execution succeeded; `False` if an error occurred |
| `latency_ms` | `float` | Request roundtrip latency in milliseconds |
| `error` | `Optional[str]` | Human-readable error message on failure; `None` on success |
| `prompt_tokens` | `int` | Authoritative provider-reported input token count |
| `completion_tokens` | `int` | Authoritative provider-reported output token count |
| `raw_response` | `Optional[dict]` | Provider JSON response dictionary for debugging |

## 5. Connecting Token Counting, Cost Tracking & Telemetry

Here is how to wire these modules into the central routing loop of the main orchestrator:

```python
import asyncio
from app.providers import OpenAICompatibleProvider, ModelDescriptor
from app.utils.token_counter import count_tokens
from app.analytics import CostTracker, MetricsCollector

# 1. Initialize global singleton services
cost_tracker = CostTracker()
metrics_collector = MetricsCollector()
provider = OpenAICompatibleProvider()

async def orchestrate_request(prompt: str, model: ModelDescriptor, context: dict = None):
    # Step A: Pre-execution token check & routing estimation
    estimated_prompt_tokens = count_tokens(prompt, model_name=model.model_id)
    if estimated_prompt_tokens > model.context_window:
        raise ValueError(f"Prompt exceeds model context window ({estimated_prompt_tokens} > {model.context_window})")

    # Step B: Register model descriptor pricing with the cost tracker
    cost_tracker.register_model_descriptor(model)

    # Step C: Execute model call
    result = await provider.call(prompt, model, context)

    # Step D: Record metrics in telemetry
    metrics_collector.record_execution(result)

    # Step E: Record actual cost using authoritative provider token counts
    if result.success:
        cost_breakdown = cost_tracker.record_execution(result, model=model)
        print(f"[Cost] Request cost: ${cost_breakdown.total_cost:.6f}")

    return result
```

## 6. Compatibility Assumptions to Confirm with Akash

Because integration has not been tested against Akash's private application code directly, please verify these points during integration:

1. **Error Handling Mode:**  
   By default, `call()` catches provider errors, timeouts, and HTTP status codes, returning `ExecutionResult(success=False, error=...)`. If Akash's orchestrator relies on catching Python exceptions instead, pass `raise_on_error=True` when instantiating the provider.
2. **Anthropic Max Tokens:**  
   The Anthropic API strictly requires a `max_tokens` parameter. If none is passed in `context["max_tokens"]`, the adapter defaults to `1024`.
3. **Environment Variable Names:**  
   Provider A checks `LLM_API_KEY` (and `OPENAI_API_KEY` as fallback), `LLM_BASE_URL` (default `https://api.openai.com/v1`), and `LLM_TIMEOUT` (default `30.0`). Confirm that Akash's deployment environment sets these names.
4. **Token Usage Authority:**  
   Pre-execution token counting via `count_tokens()` is an estimate for routing and threshold checks. Provider-reported token counts on `ExecutionResult` are authoritative for accounting.
